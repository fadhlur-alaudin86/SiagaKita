1. ARSITEKTUR & ROLE
===========================================================================

  Desktop Console diakses oleh 3 role:
    ┌────────────────┬───────────────────────────────────────────────────┐
    │ Role           │ Kemampuan                                         │
    ├────────────────┼───────────────────────────────────────────────────┤
    │ superadmin     │ Buat akun admin                                   │
    │ admin          │ KYC relawan, manajemen user, gamifikasi, statistik│
    │ agency         │ Monitor SOS, dispatch, laporan, peta real-time    │
    └────────────────┴───────────────────────────────────────────────────┘

  Login khusus console: POST /api/v1/auth/console/login
  Hanya role superadmin, admin, dan agency yang diizinkan masuk.

  Shell navigasi terpisah per role:
    - InstansiShell → untuk role agency
    - AdminShell    → untuk role admin & superadmin

4. ALUR AUTENTIKASI CONSOLE
===========================================================================

  [App Start]
       │
       ├── Cek JWT tersimpan (flutter_secure_storage)
       │     ├── Ada → reconnect WebSocket → masuk ke shell sesuai role
       │     └── Tidak ada → LoginScreen
       │
  [LoginScreen]
       │  Email + Password → POST /api/v1/auth/console/login
       │  Response: { access_token, refresh_token, user: {id, email, role, full_name} }
       │
       ├── role = "agency"     → InstansiShell(token, ws)
       ├── role = "admin"      → AdminShell(token, ws)
       └── role = "superadmin" → AdminShell(token, ws)
            [Error] role lain   → Tampilkan pesan "Akun tidak memiliki akses console"

5. WEBSOCKET (WsService)
===========================================================================

  Koneksi: ws://<host>:8081/ws/connect?token=<jwt>

  Event yang didengarkan:
    INCOMING_EMERGENCY  → Tambah ke live list + mainkan alarm.mp3
    SOS_CANCELLED       → Hapus dari live list + stop alarm
    RESCUE_ACCEPTED     → Update status dispatch
    LOCATION_UPDATE     → Update posisi marker di peta

  WsService adalah ChangeNotifier Provider — semua halaman subscribe stream yang sama.
  Indikator koneksi ditampilkan di sidebar (lingkaran hijau/merah) dan header.

9. SKEMA DATABASE — TABEL TERKAIT CONSOLE
===========================================================================

  users
    id, email, password_hash, role (superadmin|admin|agency|...), created_at, deleted_at

  admin_profiles
    user_id (FK→users), full_name, created_by (FK→users), created_at, updated_at
    → Hanya untuk role admin & superadmin.

  agencies
    id, name, type (police|fire|medical|sar), city_code, hotline_number,
    account_id (FK→users — akun agency di tabel users)
    → Nama instansi dan tipenya. Tidak ada tabel profil terpisah untuk agency.

  agency_personnels
    user_id (FK→users), agency_id (FK→agencies), full_name, badge_number, is_active
    → Personel instansi. Login via /auth/personnel/login (Mobile Responder App).

  sos_strikes
    id, user_id, incident_id, reason, marked_by (FK→users admin), created_at
    → Audit log false alarm. Strike count disimpan di user_profiles.sos_strike_count.
