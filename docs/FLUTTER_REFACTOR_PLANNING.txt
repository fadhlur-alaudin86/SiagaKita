Untuk frontend yang berbasis Flutter (baik aplikasi mobile maupun konsol desktop/web), fokus utamanya adalah menjaga FPS tetap stabil di 60/120 FPS agar responsif saat menangani data darurat yang masuk secara real-time.

Teknik: RepaintBoundary & const Constructor.
Status: SUDAH DIIMPLEMENTASIKAN pada Radar SOS, Telemetri, dan List Aktif.
Manfaat: Memisahkan proses painting area dinamis dari area statis, mencegah UI Lag.

2. Gunakan Isolate untuk Tugas Berat - [DONE]
Teknik: Isolate.run() untuk parsing JSON.
Status: SUDAH DIIMPLEMENTASIKAN di `IncidentService` (Mobile) dan `WsService` (Console).
Manfaat: Main thread (UI) tetap lancar meskipun menerima payload JSON besar dari backend.

3. Efisiensi State Management - [PENDING]
Teknik: Selector / context.select().
Rencana: Refactor Provider di Console App agar widget hanya rebuild saat data spesifik berubah.

4. Caching & Local Database - [PENDING]
Teknik: Isar atau Hive.
Rencana: Migrasi dari SharedPreferences ke Isar/Hive untuk penyimpanan cache data insiden yang lebih besar dan cepat.

5. Network Layer - [STABLE]
Teknik: Dio + Protobuf.
Rencana: Gunakan Protobuf jika transmisi data koordinat GPS meningkat tajam di masa depan.
